0.9.0
Oct 25, 2026
GitHub Release

Transcription, in your language

Until now the language was a menu in the footer. Whatever it said when a file arrived was the language that file got, so files in different languages one after another meant changing the menu in between, and forgetting it meant a transcript in the wrong language. 0.9.0 asks for every file, link and recording instead. The speech recognition is the same as in 0.8; what changed is how a file gets to it.

One question per file

When I drop a file, paste one or a YouTube link with ⌘V, or choose files from the window, the New Transcription area asks which language is spoken in it. It shows the name and one Choose Language menu, and nothing is preselected: the app doesn't guess. Choosing a language starts the transcription. The three languages I used most recently sit at the top of the menu, so switching between them is one click, and every other supported language is right below.

Several files at once are offered one at a time. I can give the next one its language while the first is still transcribing; they run one after another, in order. Remove skips a file without touching the original.

Record first, decide later

A recording is now saved to its own folder before the app asks for its language. If I quit before answering, nothing is lost: the next time the app opens, it offers the recording again and writes the transcript next to the audio. Closing the window while recording still asks first, and the saved recording waits for its language in another window. A crash or a force quit during a recording still loses it.

The transcript comes to me

In 0.7 and 0.8 a finished transcript only appeared in the library with a New badge. Now, when everything I started in a window is done, that window opens the last transcript it saved. If I have opened something else in the meantime, it leaves me there, and a run that only failed opens nothing.

A calmer place to start

The New Transcription screen is one compact surface: the drop area, and below it a single row to record an app's audio, the microphone or both, under the waveform mark. Transcribe at the top of the sidebar brings me back to it and stays selected while it is shown. New Folder is the plus button next to Folders. The footer keeps only the output folder and Settings.

The sixth language

While testing all of this, a transcription in a sixth different language failed with "Too many allocated locales". Apple lets an app keep only a few languages reserved at a time, five on my Mac, and the app never gave one back. Now, when a new language needs room, it releases the one it used least recently. macOS may then remove that language's files, so using it again can mean another download, and until then it may not work offline.

The app still doesn't detect the language by itself, and the recognition is Apple's. Dutch transcripts can still come back thin.
