0.2.0
Sep 30 – Oct 1, 2026
Development milestone

One file was no longer enough

With several recordings, the work was in the repeats: choose the language again, save again, start the next one again.

Five rounds of the same routine

In 0.1.0, five files meant five rounds of drop, pick a language, transcribe, wait, save and start over. No single step was hard. Together they meant sitting next to the app for the whole batch. The goal for v0.2, worked on over September 30 and October 1, was to remove the steps I kept repeating.

A queue that saves its own work

The single-file screen became a queue. Jobs run one after another and each keeps its own language, so a Russian recording and an English one can share a batch. When a job fails, the rest keep going. You can remove a job that hasn't started yet and clear a finished batch without relaunching the app.

Saving stopped being a step. You pick an output folder and a default language once, and the app remembers both across launches. Each finished job goes straight into that folder and never overwrites anything: a second beta.md is saved as beta 2.md.

Using the queue also showed settings in the wrong place. The empty window asked for a language, an output folder and a YouTube option before anything was in it. Those moved into the queue, together with an Apply to all button that sets one language on every waiting job.

Links in the same line

YouTube links joined the queue next to files. The app downloads a link's audio only when its job starts, passes it to the same transcription code as everything else, and deletes the download when the job ends. For research and archive use, a link can instead be kept as a source package: a folder named after the video ID with the audio, a small source.json that the app defines itself, and the transcript.

Technical note

Downloads use a pinned yt-dlp on a bundled Python 3.13 helper. The helper runs inside the app's sandbox with only the app-sandbox and inherit entitlements, and it never updates itself.

A summary line and per-job Retry finished the milestone. Its acceptance test was a short scene: paste five real YouTube links, choose English once, choose the output folder once, turn on source packages and walk away. It came back with five complete packages, and no Save dialog, Terminal command or typed filename along the way.

v0.2 was a development milestone. It never got a release of its own, and the app's version number still read 0.1.0.
