Journal

Notes on how Local Transcriber changes from one release to the next, and why. Most of the steps came from using it and taking out work I kept doing by hand.

  1. 0.4.0
    Oct 6–7, 2026
    GitHub Release

    Making its own media

    Local Transcriber used to transcribe media that already existed. 0.4.0 lets it record its own and hands the recording to the same queue as everything else.

  2. 0.3.0
    Oct 2–6, 2026
    GitHub Release

    Leaving the development machine

    Signing, notarization, a DMG and a test as a new user: the work that took Local Transcriber from the Mac it was built on to a download other people can run.

  3. 0.2.0
    Sep 30 – Oct 1, 2026
    Development milestone

    One file was no longer enough

    Several recordings meant choosing the language, saving and starting over every time. 0.2 turned that routine into a queue that runs without me.

  4. 0.1.0
    Sep 27–28, 2026
    Development build

    It started with one file

    The smallest version that worked: drop in a recording, pick a language and get timestamped Markdown back, all on the Mac.
