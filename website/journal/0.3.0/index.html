0.3.0
Oct 2–6, 2026
GitHub Release

Leaving the development machine

Until this point Local Transcriber ran on the Mac it was built on. 0.3.0 is the version someone else can download, open and check.

What a download needs

The app got an icon, built from the same seven-bar waveform mark as this site. It also got a correct version number. The build still called itself 0.1.0, so it went straight to 0.3.0. The bundled Python and yt-dlp come with their own licenses, and those notices now ship inside the app and appear in its About panel.

Two changes to the transcript

Before the code was frozen for signing, two small changes went into the transcript itself. When Apple's main speech module doesn't support a language, the app falls back to its dictation module. That happens for Dutch, Russian, Turkish and Swedish, and the fallback was running without punctuation. A before-and-after comparison in those four languages found no changed words and timestamps within a fraction of a second. Dutch and Swedish gained sentence punctuation while Russian and Turkish came out the same, so punctuation is now on.

Every transcript also has a new Transcriber line that names the module that produced it, so you can see which path a file took.

Signed, notarized, downloaded

The app and its sandboxed Python helper are signed with a Developer ID and notarized by Apple. The helper was the main notarization risk, and it went through with no issues. It ships as a 15 MB DMG for Apple silicon only, built by scripts so that the same commit gives an equivalent download.

The last check was a first run as a new user, from a separate macOS account on the same Mac: download with Safari, drag to Applications, open it, then transcribe a local file and a YouTube link. A second account is not a clean machine, and the release notes say so. After that, 0.3.0 went out as the first GitHub Release, with its SHA-256 published next to the DMG.
